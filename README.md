#Учебный проект по обработке данных в питоне. 

Выполненные задачи:

1) написать скрипт, в котором:
  1. Будет происходить обращение к нашему API для получения данных
  2. Данные будут обрабатываться и готовиться к загрузке в базу данных
  3. Обработанные данные будут загружаться в локальную базу PostgreSQL, которую вы развернули на своем компьютере или в облаке
  4. Во время обработки будет сохраняться лог работы скрипта с отлавливанием всех ошибок и выводом промежуточных стадий (например, скачивание началось / скачивание завершилось / заполнение базы началось и т.д., с трекингом времени). Лог нужно сохранять в текстовый файл. Файл нужно именовать в соответствии с текущей датой. Если в папке с логами уже есть другие логи - их необходимо удалять, оставляем только логи за последние 3 дня.

2) написать код, который в конце будет агрегировать данные за день. Например:
  1. сколько попыток было совершено;
  2. сколько успешных попыток было из всех совершенных;
  3. количество уникальных юзеров;
  4. можете добавить все, на что у вас хватит фантазии.
  И загрузите это все в табличку в Google Sheets
